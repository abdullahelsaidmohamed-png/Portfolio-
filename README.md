# Abdullah EL-Sayed Mohamed Portfolio Website

Static portfolio website with bilingual EN/AR interface, animations, ERP screenshots, event gallery, CV download and contact links.

## How to run
Open `index.html` directly in your browser, or serve the folder with any static server.

## Deploy quickly
- Netlify: drag and drop this folder or the ZIP file.
- Vercel: import as a static project.
- GitHub Pages: push the folder contents to a repository and enable Pages.

## What is included
- `index.html` - main page
- `style.css` - all styles and animations
- `script.js` - language toggle, theme toggle, particles, counters, filters, lightbox and scroll effects
- `assets/screens` - ERP system screenshots
- `assets/events` - event/workshop images
- `assets/docs` - CV PDF
